# Oleh Koliadiuk — Portfolio

A clean, responsive portfolio for showcasing selected projects, tools, and contact details.

## Overview

This project is a lightweight static portfolio built with HTML, CSS, and JavaScript. The site focuses on clear typography, editorial spacing, subtle motion, and accessible interactions without unnecessary framework overhead.

## Structure

- `index.html` — main page content and sections
- `css/main.css` — layout, styling, and interaction states
- `css/animations.css` — motion and reduced-motion behavior
- `js/app.js` — app bootstrap
- `js/ui.js` — navigation, selection states, and scroll progress
- `js/animations.js` — reveal-on-scroll behavior
- `assets/favicon/` — browser and app icons
