## About

This is the personal portfolio of Oleh Koliadiuk, a frontend developer based in Rivne, Ukraine. It introduces his approach to building clear, thoughtful web experiences and presents a hand-picked selection of projects from GitHub.

The site uses a clean editorial layout, warm neutral colors, and subtle motion to keep the focus on the work. It is built with native web technologies and does not rely on a frontend framework or runtime dependencies.

## What’s inside

- Responsive pages and accessible navigation for desktop, tablet, and mobile
- An introduction and a visual summary of the tools used
- Selected project cards with source code links and keyboard-accessible highlighting
- Contact links and a direct email call to action
- Custom favicon set for browser tabs, Apple devices, and Android devices
- Scroll progress, pointer-responsive details, and section reveal animations
- Reduced-motion support

## Built with

| Technology | Use |
| --- | --- |
| HTML5 | Semantic page structure and content |
| CSS3 | Responsive layouts, visual styling, and animations |
| JavaScript ES modules | Navigation, project-card interactions, scroll progress, and animation setup |
| Intersection Observer API | Triggering reveal animations as content enters the viewport |
| Web app manifest | App name, theme colors, and Android icons |

### Source files

- `index.html` contains the portfolio content, navigation, and featured projects.
- `css/main.css` defines the visual system, responsive layout, and interaction states.
- `css/animations.css` contains motion effects and reduced-motion rules.
- `js/app.js` initializes the site modules.
- `js/animations.js` handles scroll-based reveal animations.
- `js/ui.js` manages the mobile menu, project-card selection, pointer effects, and scroll progress.
- `assets/favicon/` contains the browser, Apple, and Android icons plus the web app manifest.

## Featured projects

- **Random Quotes Generator** — A quote app with light and dark themes, clipboard support, saved preferences, and a usage counter.
- **To-Do List** — A responsive task manager with persistent tasks and completion tracking.
- **Cyber Dev Clicker** — A strategy clicker with layered progression, passive income, and scalable upgrades.
